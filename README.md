# Конструктор навыков

Готовый проект на Vite + React. Ниже — как выложить его на GitHub и подключить автодеплой на Vercel.

## Важно про данные

В версии из чата использовался `window.storage` — это API, которое существует только внутри превью Claude. Здесь я заменил его на обычный `localStorage` браузера (см. верх `src/App.jsx`). Это значит:
- Библиотека иконок и заполненные ячейки сохраняются в браузере, в котором ты открыл сайт.
- Если открыть сайт с другого устройства или в другом браузере — данных там не будет, это чистый локальный кэш конкретного браузера, без общего сервера.
- Если тебе позже понадобится доступ к данным с разных устройств — нужна будет настоящая база данных на бэкенде, это отдельная задача.

## Шаг 1. Залить код на GitHub

**Вариант А — без терминала (удобно с телефона):**
1. Зайди на github.com → New repository → дай имя (например `skill-constructor`) → Create repository.
2. На странице пустого репозитория нажми «uploading an existing file».
3. Перетащи туда все файлы и папки из этого архива (сохранив структуру: `src/App.jsx`, `src/main.jsx` и т.д.).
4. Commit changes.

**Вариант Б — через git (если работаешь с компьютера):**
```bash
cd skill-constructor-app
git init
git add .
git commit -m "init"
git branch -M main
git remote add origin https://github.com/ТВОЙ_ЛОГИН/НАЗВАНИЕ_РЕПО.git
git push -u origin main
```

## Шаг 2. Подключить Vercel

1. Зайди на vercel.com, войди через GitHub-аккаунт.
2. «Add New» → «Project» → выбери свой репозиторий.
3. Vercel сам определит, что это Vite-проект (Framework Preset: Vite) — ничего менять не нужно.
4. Нажми Deploy.

Через минуту сайт будет доступен по адресу вида `название-репо.vercel.app`.

## Дальше

Теперь любой коммит в ветку `main` (через git или прямо на github.com, даже через встроенный редактор github.dev) автоматически пересобирает и обновляет сайт на Vercel — именно то поведение, которое ты описал.

## Локальный запуск для проверки (по желанию)

Нужен установленный Node.js.
```bash
npm install
npm run dev
```
